### Hey! I'm Diego

I'm a bioinformatician / software developer specialized in building Nextflow pipelines and doing data analysis in Python and R. I love automating things and creating nice visualizations and beautiful documents. I’m a strong advocate for open science and reproducible research.

When I'm not exploring genomic data, I'm probably doing some web development with Litestar/FastAPI and Vue/Nuxt, or tinkering with Linux systems.

Active contributor of the [nf-core](https://nf-co.re/) community, particularly maintaining the [nf-core/mag](https://github.com/nf-core/mag) pipeline.
